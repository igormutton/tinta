# Tinta

Leia `AGENTS.md` antes de qualquer mudança. Ele contém as regras de ativos, clean-room,
automação, segurança contra travamentos e os comandos de qualidade.

Comandos úteis:

- `cargo run --release -p tinta -- arquivo.pdf` abre o app desktop.
- `cargo run -p tinta-cli -- tools` lista as ferramentas de automação.
- `cargo test -p <crate>` roda os testes de um crate.
