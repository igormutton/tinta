Tinta portable mode

While this file sits next to tinta.exe, Tinta keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the TintaData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Tinta with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Tinta and
%LOCALAPPDATA%\Tinta) instead. If TintaData can't be written (for example on a read-only
drive), Tinta says so and uses the per-user folders instead.
